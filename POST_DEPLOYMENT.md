## Scaling Upgrades

### When to Upgrade Vercel
- Bandwidth > 100GB/month
- Need preview deployments
- Need advanced analytics
**Upgrade:** Vercel Pro ($20/month)

### When to Upgrade Neon
- Database > 200MB
- Need more compute
**Upgrade:** Neon Launch ($19/month)

### When to Upgrade Resend
- Emails > 100/day
- Need dedicated IP
**Upgrade:** Resend Pro ($20/month)
